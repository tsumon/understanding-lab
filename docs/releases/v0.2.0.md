# Understanding Lab v0.2.0

## 中文

12 章中英双语互动 AI 课程正式静态版：数据划分、回归、过拟合、梯度下降、分类、神经网络、嵌入、注意力、生成、RAG、评估与安全。每章包含讲解、预测反馈、本机确定性实验、迁移练习、测验订正、反思与原始来源；原版过拟合课程独立保留。

- **下载即用：** 解压 `understanding-lab-0.2.0-static.tar.gz`，在解压目录运行 `python3 serve.py`（Python3.9+；Windows 可用 `py serve.py`），打开 http://127.0.0.1:4173/。无需 Node、npm、账号或模型密钥。
- **离线与数据保护：** 等待缓存就绪后支持离线学习；课程记录独立存储。提供记录导出、损坏记录保护、跨标签页冲突提示及未保存内容的更新保护。升级前导出两套记录，保持同一浏览器、主机名和端口，不要清除站点数据。
- **发布加固：** 完整打包许可证和 SHA-256 校验、确定性归档、仅回环监听的本地启动器，以及 service-worker 升级与记录保留验证。修复已确认的原版草稿重挂载、跳转链接、导师取消窗口及 FFmpeg EPIPE 生命周期问题。
- **交互稳定性：** 离线缓存与更新提示预留布局空间，避免异步状态变化把正在点击的按钮移走。
- **输入兼容性：** 原版解释框直接处理标准 input 事件，保留未确认草稿、中文组合输入及长度保护；不把此健壮性改进宣称为已证明的历史 WebKit 唯一根因。
- **安全补丁：** 更新经核验的 Better Auth、Zod、Vite、Vitest 及相关传递依赖；候选验证时 `npm audit --omit=dev` 无已知漏洞，不代表绝对安全。

本次是**匿名本机静态课程**发布，不包含托管账号 / AI 服务、公开域名部署或付费供应商启用。课程完成记录不是掌握认证；教学有效性、真实 OAuth、实体设备语音及生产运维仍不在此次验收范围。localStorage 可能被清除/回收且不加密；课程导出暂无导入界面，跨标签页检查不是原子事务。历史 WebKit 间歇现象保留记录，不以一次通过宣称永久消失。

稳定版发布以同一提交的完整 CI 成功为前提。候选基线 `7ecf750` 的两次完整 CI 均通过：372 单元测试、6 数值测试、42 fixture 评估、137 浏览器测试，13 项原有跳过。历史失败与修复证据见 `docs/verification/`；新版本完整结果见发布提交的 GitHub Actions，不将旧结果冒充新提交测试。

## English

A standalone, bilingual 12-chapter AI course with explanations, predictions, deterministic experiments, transfer practice, corrected knowledge checks, reflection and sources. The original overfitting lab is retained separately.

Extract the static archive, run `python3 serve.py` with Python3.9+ (or `py serve.py` on Windows), then open http://127.0.0.1:4173/. No npm, Node.js, account or model key is required. Verify the supplied SHA-256, and wait for the cache-ready status before going offline.

This release adds local course progress, exports, corruption/conflict protection, safe update handling, complete bundled licenses and reproducible packaging. It includes verified fixes for legacy draft remounting, skip-link routing, tutor request cancellation and FFmpeg pipe-error cleanup, plus reviewed dependency security patches. Offline status and update notifications reserve layout space so asynchronous messages do not move an in-progress pointer target. The legacy answer field also handles standard input events directly while preserving draft and length rules; this robustness improvement is not claimed as proof of the unique historical WebKit failure cause.

**Scope:** anonymous local static learning, not a hosted account/AI service launch. Export progress before updates; preserve browser/origin and do not clear site data. Browser storage is neither encrypted nor durable backup. Completion does not certify mastery; human teaching effectiveness, real OAuth/providers, physical-device voice and public production operations remain outside acceptance. Known historical WebKit intermittency is documented rather than declared permanently eliminated.
