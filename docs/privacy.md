# 隐私与数据边界

匿名本机试玩不需要登录，不上传本地回答或私人笔记。当前界面使用固定题目并标注“离线引导，不是 AI 评价”。导入登录辅助模块不启动网络请求；登录是单独的明确操作。登录不等于上传：识别身份或完成 GitHub 登录都不会自动上传匿名草稿。

账号登录由 Better Auth 和部署者配置的 GitHub OAuth 应用处理。申请的权限只有 `read:user` 和 `user:email`，用于识别账号、获取账号资料与必要的 email 身份信息，不申请仓库权限。email 仅用于账号识别与认证记录，不作为教学内容发送给模型，也不用于营销。认证记录及会话存放在部署者持久磁盘的 SQLite 中。Cookie 为 HttpOnly、SameSite=Lax、仅当前主机，公开 HTTPS 部署使用 Secure；退出登录清除 cookie 并撤销服务端会话。

“发送给 AI”和“保存到账号”是两个独立同意：发送文字不默认长期保存，保存到账号不默认调用模型，私人笔记默认不发送（`includeNotes` 默认 false，需额外勾选）。登录不会自动上传匿名草稿。账号学习记录的读取、修改、导出、删除都检查记录所有者；外人与不存在统一为 404，本人已删除为 410。客户端上传的反馈正文可以恢复，但 model / promptVersion 固定为“本机恢复”，不能当作供应商调用证明。教学调用只在使用者点击「发送给 AI」且请求带 `sendConsent: true` 后发出；保存到账号不会请求 `/api/tutor`。额度按 UTC 日期计算：每账号每天最多 30 次教学、10 次转写。转写需要单独点「转写这段录音」；结果只进入可编辑草稿，确认前不会调用教学模型。音频只为当次转写在服务端内存中处理，本应用默认不保存原音。第三方供应商是否留存由部署者选择的模型与政策决定，上线前须披露实际政策链接，不能写成全链路零留存。

部署者的密钥只保存在服务端环境变量中，不使用 `VITE_` 前缀，不放入浏览器包。应用日志只记录固定事件和经过归类的失败原因，不记录请求正文、email、cookie、密钥、学习文字或原始错误对象。所有服务响应设置 `Cache-Control: no-store`。模型供应商的数据保留政策须由部署者确认并向使用者披露；当前教学适配器请求设置 `store:false`，这不代表供应商完全不保留请求。

`TUTOR_ENABLED` 默认 `false`。明确启用且配置完整时，每次进程启动会发送一次不含用户资料的兼容性探测，可能产生费用，包括进程管理器重启。成功探测仅证明观察到的输出结构兼容，不代表教学质量已验收。真实 OAuth 与供应商数据政策、模型兼容性仍需部署者在正式启用前验证。

导出 JSON 只含本次尝试的主题/实验包版本、确认文字、快照、反馈和异议，不含 cookie、token、API key 或第三方用户标识。导出再读入只作为本机恢复，必须再次明确保存才会上云，也不能复活已删除的云端 ID。删除账号记录后，服务端 GET/export 不能取回正文；其他设备上的离线副本不会立即消失。墓碑阻止用旧编号重放。备份保留期限由部署者自行披露；本仓库不承诺 7 天删除，也不承诺端到端加密。没有书面备份与恢复演练时，不得公共部署。

形成性测试若记录学习者数据，须事先同意并去标识化。5 人观察不能用来宣称效率百分比。
